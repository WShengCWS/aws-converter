What this converter does

    

      

        
🧹 Row Filtering

        
Rows with upfront cost are kept and totalled. Rows where both upfront AND monthly are zero/empty are removed.

      

      

        
📊 Excel Table

        
Full Excel Table (TableStyleLight8) injected via JSZip. All cells centre + middle aligned except Configuration Summary (left-aligned).

      

      

        
Σ Range Formulas

        
Totals use SUM(). Upfront column totalled separately. First 12 months = (Upfront + Monthly×12) per row. Comma format on all numeric columns.

      

      

        
🏳 Orange Total Row

        
Total row filled FCE4D6 (Orange Accent 2 Lighter 80%) with bold text. Configuration summary column is left-aligned. No Excel repair errors.
